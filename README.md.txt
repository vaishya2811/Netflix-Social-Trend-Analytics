# Netflix Social Trend Analytics

## Project Overview

This project analyzes Netflix Movies & TV Shows and IMDb Top 1000 Movies using Python, SQL, and Power BI.

The objective is to uncover content trends, audience preferences, country-wise production patterns, and rating distributions to understand how streaming platforms evolve over time.

---

## Tools Used

* Python (Pandas, NumPy, Matplotlib)
* SQL (SQLite)
* Power BI
* Git & GitHub

---

## Dataset Sources

### Netflix Dataset

* 8,807 Netflix titles
* Movies and TV Shows
* Countries, ratings, genres, release years

### IMDb Dataset

* Top 1000 Movies
* IMDb Ratings
* Runtime
* Votes
* Genres

---

## Project Workflow

### 1. Data Cleaning (Python)

* Handled missing values
* Converted date formats
* Created Year Added column
* Removed inconsistencies

### 2. Exploratory Data Analysis

Key insights discovered:

* Movies dominate Netflix content
* United States and India produce the most Netflix content
* TV-MA is the most common maturity rating
* Netflix experienced rapid growth after 2015

### 3. SQL Analysis

Performed:

* Aggregations
* Group By analysis
* CTEs
* Window Functions
* Ranking Queries

### 4. Power BI Dashboard

#### Netflix Overview Dashboard

* Total Titles
* Total Countries
* Total Directors
* Total Genres
* Content Growth Trend
* Movie vs TV Show Distribution
* Country-wise Production Analysis

#### IMDb Analytics Dashboard

* Average IMDb Rating
* Total Votes
* Average Runtime
* Rating Distribution
* Votes vs Ratings Analysis
* Top Rated Movies

---

## Business Value

This project demonstrates how streaming content data can be transformed into actionable business insights.

The dashboard helps:

* Identify content growth patterns
* Understand audience preferences
* Analyze market dominance by country
* Evaluate movie quality using ratings and votes
* Support strategic content acquisition decisions
